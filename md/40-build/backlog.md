## 目录安装的排除后缀

背景：`lb install <目录>` 会安装目录内全部 deb/LBPA。测试时需要临时排除部分包（例如缺依赖的 `cowsay`），但又要保留它们参与依赖分析，用来构造异常依赖场景。

期望行为（草案）：

- `lb install <目录> --exclude-suffix .skip`（可多次指定）跳过以该后缀结尾的文件，不安装
- 被排除的包**仍参与依赖图计算**：依赖它们的包能算出顺序，它们自身的缺失依赖也会被报出
- 排除只影响“装哪些”，不影响“依赖怎么算”
- 未指定排除后缀时行为不变

- 是否同时支持 `--exclude <包名>`
